LUA OBFUSCATOR

A little tool I made with AI to quickly obfuscate Lua 5.4 and Roblox Luau scripts and code locally on 64-bit Windows.

INSTALL

1. Download the latest release ZIP.
2. Extract the complete folder.
3. Double-click Installer.bat.
4. Press Y once to approve setup.
5. Leave the setup window open until every check passes.
6. Double-click the Lua Obfuscator shortcut created in the folder.

Keep the full extracted folder path at 72 characters or fewer so Windows can install the private packages reliably.

USE

1. Choose a .lua, .luau, or .txt source file.
2. Select Lua 5.4 or Roblox Luau.
3. Select low, medium, or high obfuscation.
4. Choose the output folder.
5. Click Obfuscate.

SETUP DETAILS

Setup keeps official Python 3.14.7, PySide6-Essentials, Hercules, Lua 5.4.8, settings, and app-specific files private to this folder. It does not require administrator access, change PATH, or install global Python packages. Downloaded runtime archives are verified before use.

Setup creates and validates a normal Lua Obfuscator shortcut in this folder. Run Installer.bat again to repair setup or after moving the complete folder. Your source files are never changed by setup.

PRIVACY AND REMOVAL

The app has no telemetry, analytics, advertisements, accounts, uploads, or runtime network requests. Scripts are processed locally. Review setup.log before sharing because it can contain local folder paths.

To remove this tool, close it and delete the extracted folder. The shared Fleece Tools .pyw launcher can be restored later with the helper in %LOCALAPPDATA%\Fleece Tools\Python Launcher after every Fleece Tool is closed.

TROUBLESHOOTING

If setup or the shortcut fails, review setup.log and run Installer.bat again. Success is shown only after the dependencies, offline self-tests, and shortcut all pass. Keep the complete extracted folder together.

Lua and Hercules are installed privately by Installer.bat. A separate system-wide Lua installation is not required.
